## Code Style & Behavior: No Comments Rule

- **Strictly Avoid Comments:** Do not write inline comments, block comments, or explanatory comments inside the code files unless explicitly requested by the user.
- **Self-Documenting Code:** Write clean, expressive, and self-explanatory code using meaningful variable, function, and component names instead of relying on comments.
- **Explanations:** Keep all explanations, rationale, and notes within the chat response, never inside the code artifacts or files.
